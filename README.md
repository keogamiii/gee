# NEON VOYAGER

Интерактивная одностраничная космическая станция. Без фреймворков и зависимостей — чистые HTML, CSS и JavaScript.

## Что внутри

- **Звёздное поле** на `<canvas>` с параллаксом за курсором и вспышками по клику.
- **Мини-игра «Ловец комет»** — 30 секунд, серии-множители, рекорд в `localStorage`.
- **Неоновый синтезатор** — 8 нот мышкой или клавишами `1`…`8` (Web Audio) + визуализатор.
- Курсор-свечение, появление блоков при скролле, конфетти-сюрприз.

## Запуск локально

```bash
node server.js
# откроется http://localhost:8080
```

Или просто открой `index.html` в браузере.

## Публикация

Хостится на GitHub Pages прямо из корня репозитория.
